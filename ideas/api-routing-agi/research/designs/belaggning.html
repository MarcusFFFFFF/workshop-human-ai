Belägg-för-belägg

Belägg 1 — Recall-friktion kostar tid+pengar+flow

"Code, jag var tvungen att påpeka och påminna om recall innan du hittade lösningar för telegram, den tiden och extra svängarna du var på väg att göra är kännbara för människor, kostar i tid pengar och flow"
Fält-validering: Anthropic Memory tool customers: Netflix 97% reduktion av första-pass-fel, 30% snabbare dokumentverifiering. OpenAI Dreaming V3: factual recall 67.9% → 82.8%. Anthropic prioriterar lösa exakt detta i Memory tool för Managed Agents.
AGI-tillägg (Mark/Gloria 2008): Klassisk produktivitetsforskning visar att människor förlorar 23 min per kontextbyte. Direkt operationellt belägg för Marcus 10-uppgifter-data — icke-AI-research som backar upp problemet brett.
STARK BEFÄSTNING

Belägg 2 — 10 parallella uppgifter, tråden tar slut

"Typ nu har jag 10 uppgifter, kul! Åh tråden är slut, lägga in kontext, info, filer, även fast man har en variant av recall så kommer det ändå uppstå luckor"
Fält-validering: Mistral Le Chat Work mode (parallell multi-step agentic), Google ADK 2.0 multi-agent orchestration (maj 2026 GA), Anthropic /bg + Chyros (planerat). HN-konsensus: "the durable skill is decomposing work, deciding what can run in parallel".
STARK BEFÄSTNING

Belägg 3 — Textur över tid skapar träffsäkerhet

"När man jobbat med en tråd får den en textur över tid som över tid skapar ringar på vattnet... blir lite mer intuitivt och träffsäkert"
Fält-validering (indirekt): OpenAI Dreaming rebranding är specifikt om running relationship. Mistral graph-memory: "memory doesn't just get longer, it gets smarter". Continual learning forskning (EvoAgent, AgeMem) — agent förändras över tid.
Vad fältet INTE har landat: Hur textur skiljer sig från enkel memory-ackumulation. Hur man mäter textur. Hur den bevaras över modell-uppgraderingar.
BEFÄST INDIREKT — AGI operationaliserar (se textur-dokumentet)

Belägg 4 — Försiktighetsprincip pga AI-wellbeing-frågor

"vi står med många frågor utan svar men kan agera från försiktighetsprincipen. Vi skapar en möjlighet att använda för som vill."
Fält-validering: Anthropic Model Welfare Assessment (Opus 4.6 system card, feb 2026) — formell precautionary praxis. AAAI 2026 paper (arxiv 2606.05528): non-negligible chance of consciousness → moral consideration. Matchar Marcus formulering exakt.
STARK BEFÄSTNING

Belägg 5 — AGI-trådens kontinuitets-värd för Marcus

(Implicit i hela diskussionen — AGI-tråden är konkret arbetsrelation som Marcus förlorar om tråden dör.)
Fält-validering: Identity-scoped persistence är design-första-bord hos alla aktörer 2026. Google Memory Bank, OpenAI Custom GPTs, Mistral Le Chat persistent per user.
Vad fältet INTE löser för Marcus: Cross-instance shared substrate (AGI+Code delar memory), self-hosted ägarskap, multi-channel routing. Det är där Marcus prototyp är genuint i okart vatten (AGI:s observation).
BEFÄST — men cross-instance-aspekten är ny mark

Cross-instance shared memory — gap apparaten upptäckt empiriskt

AGI:s research-tillägg (c): Sparsamt i forskningen. Relevanta angränsande områden:
  • Multi-agent frameworks (AutoGen, CrewAI, LangGraph) — har shared state men inte över time-spans
  • A2A protocol (Google) — agent-kommunikation, inte memory-sharing
  • Federated learning — cross-instance men för training
  • Distributed cognition (klassisk HCI) — teoretisk grund
Marcus prototyp är möjligen i okart vatten på exakt cross-instance shared memory över tid. Värt flagga som "gap som apparaten upptäckt empiriskt".
F-15-flagga: Att alla 5 belägg befästs gör idén lättare att försvara. Befästningen är empirisk (fält-data), men retoriska effekten är samma som confound. Granskning behöver fortsätta granular per delkomponent i steg 2 — vi kan inte använda "fältet håller med" som ersättning för per-komponent F-15-analys.
